# Lurexa Brand Marks

These SVG files are the authoritative vector source assets for the Lurexa brand family.

Design principle: **shared grammar + distinct personalities**.

- `marks/lurexa-master.svg` — Lurexa Learning Technologies; institutional and foundational.
- `marks/lurexa-learn.svg` — inviting and progressive; pathway/progress metaphor.
- `marks/lurexa-coach.svg` — conversational and alive; speech/pulse/microphone metaphor.
- `marks/lurexa-teach.svg` — professional and developmental; growth/evidence pathway metaphor.
- `marks/lurexa-admin.svg` — authoritative and controlled; shield/trust metaphor.
- `marks/lurexa-insight.svg` — analytical and interpretive; evidence/lens metaphor.
- `marks/lurexa-studio.svg` — creative and constructive; modular creation metaphor.
- `marks/lurexa-docs.svg` — structured and knowledge-oriented; document/search metaphor.

## Usage

Use `MasterMark`, `ProductMark`, and `DocsMark` from `@lurexa/ui` in React surfaces instead of copying SVG markup into applications. The files in this folder exist for design/export/share workflows and for non-React uses.

Do not create a new top-level product mark for feature identities such as Teach Community. Features inherit the visual identity of their parent product.

## Canonical editable design

The editable Canva logo board is maintained separately as **Lurexa Product Logo System — Shared Grammar + Distinct Personalities**. Keep Canva exports visually aligned with these SVG masters.
