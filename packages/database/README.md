# `@lurexa/database`

Database client interface and configuration for Lurexa apps.

## Usage

```ts
import { createDatabaseConfig } from "@lurexa/database";
import type { DatabaseClient } from "@lurexa/database";
```

## Environment variables

| Variable | Description |
|----------|-------------|
| `DATABASE_URL` | Database connection string |

## Scripts

- `pnpm lint` — Run ESLint
- `pnpm check-types` — Run TypeScript type checking
