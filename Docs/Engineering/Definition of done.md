# Definition of Done

Version: 1.0

Status: Approved

---

# Purpose

A task is not complete when it works.

A task is complete only when it satisfies every engineering requirement defined in this document.

---

# Functional

- Feature implemented
- Acceptance criteria met
- Edge cases handled

---

# Code Quality

- TypeScript passes
- ESLint passes
- Formatting passes
- No duplicated logic

---

# Architecture

- Uses approved capability
- No architectural violations
- No forbidden dependencies

---

# Testing

- Unit tests added
- Integration tests updated
- Existing tests pass

---

# Accessibility

- Keyboard accessible
- Screen reader compatible
- Focus states present
- Contrast requirements satisfied

---

# Performance

- No unnecessary re-renders
- Images optimized
- Lazy loading used where appropriate

---

# Security

- Input validated
- Permissions verified
- Secrets protected

---

# Documentation

- Documentation updated
- Storybook updated (if UI)
- ADR created (if architectural)

---

# AI Requirements

If AI behavior changed

- Prompt documented
- Guardrails reviewed
- Fallback behavior verified

---

# Deployment

- Build passes
- Preview deployment verified

---

# Final Checklist

✓ Feature complete

✓ Tests pass

✓ Documentation updated

✓ Production ready
