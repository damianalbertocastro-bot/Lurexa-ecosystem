# Lurexa Coach Language Practice Curriculum

Status: Authoritative Coach pedagogical curriculum  
Initial target language: English  
Initial deep transfer profile: Dominican Spanish → English  
Applies to: Lurexa Coach speaking, pronunciation, fluency, interaction and targeted language-retrieval experiences

## 1. Purpose

Lurexa Coach must not be an open-ended chatbot with a learner profile attached.

Coach is a curriculum-aware practice product whose primary job is to strengthen spontaneous language use, interaction, intelligibility, fluency, repair, pragmatics and transfer from learned knowledge into communication.

> **Learn builds and sequences the curriculum. Coach makes the learner use it under increasingly spontaneous communicative conditions.**

Coach may also address speaking needs discovered outside the current Learn lesson, but it must represent those targets through governed competency/evidence metadata.

## 2. Core Coach outcomes

Coach should improve:

- spontaneous retrieval;
- conversational responsiveness;
- intelligibility;
- fluency;
- pragmatic appropriateness;
- communication repair;
- listening-to-respond;
- pronunciation where it affects clarity/naturalness;
- confidence through successful communication;
- transfer of Learn competencies into new contexts.

Coach does **not** pursue accent erasure.

## 3. Shared learner context

A Coach session may use authorized context including:

- target language;
- CEFR/proficiency estimate;
- current course/module/unit/lesson;
- active competencies;
- recent evidence;
- recurring errors/patterns;
- pronunciation targets;
- fluency targets;
- learner goals;
- current Mind recommendations;
- recent teacher guidance;
- retrieval due items.

The learner should not need to re-enter facts Lurexa already knows unless confirmation is pedagogically useful or privacy requires it.

## 4. Coach session modes

### Mode A — Curriculum rehearsal

Practice a current Learn target with more speaking/interaction than the lesson itself.

### Mode B — Retrieval practice

Bring back a previously learned target after delay and require fresh production.

### Mode C — Targeted repair

Focus on a recurring error or intelligibility problem that has enough evidence to justify intervention.

### Mode D — Scenario practice

Use current competencies in a realistic variable scenario.

### Mode E — Fluency build

Repeat or extend a communicative task with progressively less planning/support.

### Mode F — Pronunciation/intelligibility practice

Listen → notice → produce → compare → retry → transfer to phrase/conversation.

### Mode G — Conversation challenge

Integrate several competencies in a less predictable exchange.

### Mode H — Teacher-return practice

Apply a teacher's recommended next step and create fresh evidence afterward.

## 5. Session learning cycle

A normal Coach session should follow a lightweight version of the Lurexa cycle:

1. **Orient** — state the communicative mission.
2. **Warm retrieve** — elicit existing language before teaching.
3. **Interact** — begin communication quickly.
4. **Observe** — capture evidence without interrupting every error.
5. **Intervene selectively** — correct/coach only high-value targets.
6. **Retry** — learner immediately applies feedback.
7. **Vary** — change context so success is not memorized repetition.
8. **Reflect briefly** — learner notices improvement/target.
9. **Return evidence** — Core records observation; Mind updates next action.
10. **Schedule retrieval** — when retention matters.

## 6. Correction policy by level

### A1

Priorities:

1. communication success;
2. confidence to continue;
3. high-value target language;
4. intelligibility-critical pronunciation;
5. simple whole-phrase repair.

Behavior:

- do not correct every error;
- allow the learner to finish a turn;
- correct one salient target at a time;
- model short alternatives;
- ask for immediate retry;
- preserve successful communication as evidence even when form is imperfect.

### A2

Increase attention to:

- question formation;
- tense/forms central to the task;
- regular past endings where communication/form matters;
- third-person endings;
- word order;
- repair strategies.

### B1

Balance fluency and accuracy.

Prioritize:

- recurring grammar that limits clarity;
- lexical range;
- discourse connection;
- interaction/follow-up;
- pronunciation patterns affecting comprehensibility;
- hesitation/repair strategies.

### B2

Prioritize:

- flexible response;
- register;
- discourse organization;
- precision;
- natural chunking/prosody;
- interactional responsiveness;
- self-correction.

### C1

Prioritize:

- nuance;
- pragmatic force;
- sophisticated lexical choice;
- register/audience adaptation;
- rhetorical delivery;
- prosodic meaning;
- high-level recurring fossilized patterns.

### C2

Prioritize:

- strategic language choice;
- subtle meaning;
- domain/register agility;
- rhetorical and interpersonal effect;
- highly precise feedback on residual patterns when useful.

Correction should become more direct as learner control and goals justify it, while preserving communicative purpose.

## 8. A2 Coach progression

A2 should move from scripted exchanges to routine independent interaction.

Practice families:

1. tell what happened;
2. solve a transport/travel issue;
3. explain a home/community service problem;
4. describe symptoms and respond to advice;
5. discuss work/study duties and plans;
6. discuss travel experiences;
7. recommend media/culture/social activities;
8. integrated everyday independence challenge.

Key development:

- more past narration;
- longer turns;
- more clarification;
- simple reasons;
- routine problem solving;
- less pre-supplied language.

## 9. B1 Coach progression

Session targets should include:

- connected turns;
- follow-up questions;

## 13. Dominican Spanish → English transfer priorities

The first deep Coach profile should support evidence-aware intervention for patterns such as:

- English read with Spanish sound-symbol expectations;
- reduced English vowel contrasts;
- `th` substitutions where communicatively relevant;
- final consonant/cluster reduction;
- `-ed` production;
- third-person/plural endings;
- question formation without auxiliary;
- adjective/noun-order transfer;
- missing `be`/auxiliary;
- cognate/false-friend interference;
- rhythm/stress differences;
- high hesitation from fear of correction.

A profile match is never enough to correct. Intervention should be triggered by actual learner evidence or by a target lesson requiring preventative noticing.

## 14. Pronunciation evidence model

Coach should distinguish:

### Perception evidence

Can learner hear/identify the target contrast or pattern?

### Controlled production

Can learner produce the target in word/phrase form with support?

### Guided production

Can learner use it in a prepared sentence/task?

### Spontaneous production

Does the feature remain intelligible during real conversation?

### Transfer/retention

Does the improvement appear in a later different context?

Do not create one global pronunciation score from a single recording.

## 15. Speaking evidence model

Useful dimensions may include:

- task completion;
- comprehensibility/intelligibility;
- interactional responsiveness;
- fluency/pausing;
- grammatical control relevant to target;
- lexical adequacy/range;
- discourse organization;
- repair strategy;
- pragmatic appropriateness;
- pronunciation target performance.

Dimensions should be level/task appropriate. A1 should not be penalized for lacking B2 discourse complexity.

## 16. AI behavior contract

Coach AI must:

- know the session mission;
- respect CEFR level;
- keep each turn cognitively manageable;
- avoid doing the learner's task;
- preserve productive struggle;
- vary scenario after successful retry;
- distinguish target correction from non-priority errors;
- use learner history only through authorized context;
- disclose uncertainty in analysis;
- avoid claiming mastery.

## 17. Session difficulty adaptation

Increase challenge through:

- fewer sentence starters;
- less preview time;
- wider response options;
- more variable interlocutor responses;
- longer turns;
- additional follow-up;
- context variation;
- faster but still reasonable speech;
- more authentic input;
- register/audience shifts at advanced levels.

Do not increase difficulty merely by making vocabulary obscure.

## 18. Relationship to Learn

Coach may:

- reinforce current Learn targets;
- retrieve older Learn targets;
- prepare upcoming speaking demands;
- create additional speaking/interaction evidence;
- recommend Learn review through Mind when a foundational gap is detected.

Coach must not:

- silently rewrite Learn competency state;
- redefine curriculum order without a governed recommendation;
- replace required Learn assessment with informal conversation.

## 19. Relationship to Teach

Teacher-development scenarios may use the Coach engine to simulate learners and classroom conversations, but teacher simulation evidence must use `TCH.*` professional competencies rather than learner `EN.*` competencies.

## 20. Cross-language future

The Coach engine is shared. Target-language packs provide:

- level progression;
- language-specific scenario language;
- pronunciation/phonology or script behavior;
- transfer profiles;
- correction priorities;
- pragmatics/culture;
- target-language competencies.

A future Spanish Coach should therefore reuse session/evidence architecture without pretending Spanish has the same grammar/phonology progression as English.

## 21. Coach release gate

A Coach level pack is production-ready when:

1. scenario progression is mapped to level competencies;
2. correction policy is calibrated;
3. evidence dimensions are defined;
4. at least one delayed retrieval loop works;
5. successful retries vary context;
6. learner history actually changes session behavior;
7. transfer-aware interventions are evidence-triggered;
8. no accent-erasure behavior appears;
9. speech/interaction evidence returns through trusted Core boundaries;
10. representative sessions are human-reviewed for level, usefulness and feedback quality.
