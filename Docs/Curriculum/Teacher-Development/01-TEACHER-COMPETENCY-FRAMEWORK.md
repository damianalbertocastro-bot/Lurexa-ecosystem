# Lurexa Teach Teacher Competency Framework

Status: Authoritative professional competency model  
Depends on: `00-LUREXA-TEACH-PROFESSIONAL-DEVELOPMENT-PROGRAM.md`

## 1. Purpose

This document defines stable professional competency families for Lurexa Teach. Courses and modules generate evidence about these competencies; professional history should remain attached to competencies rather than to one course completion record.

## 2. ID convention

Recommended pattern:

`TCH.<DOMAIN>.<COMPETENCY_NAME>`

Where stage expectations are required, the stage is stored as the expected performance standard rather than creating a new competency ID for every stage.

Example:

- `TCH.DESIGN.WRITE_PERFORMANCE_OBJECTIVE`
- `TCH.ASSESS.INTERPRET_FORMATIVE_EVIDENCE`
- `TCH.DIGITAL_AI.EVALUATE_AI_OUTPUT`

## 3. Evidence dimensions

Professional competencies may include evidence for:

- conceptual knowledge;
- planning/design;
- simulated decision-making;
- demonstrated teaching;
- learner-work analysis;
- reflection;
- transfer to a new context;
- observed classroom performance;
- peer/mentor validation;
- leadership/facilitation;
- retention/revalidation.

A quiz can contribute conceptual evidence. It cannot by itself establish high-confidence teaching mastery.

# Domain 1 — Learning and the Learner (`TCH.LEARNER`)

- `TCH.LEARNER.PRIOR_KNOWLEDGE` — elicit and use relevant prior knowledge.
- `TCH.LEARNER.SCAFFOLDING` — provide and gradually remove appropriate support.
- `TCH.LEARNER.COGNITIVE_LOAD` — manage information/task complexity appropriately.
- `TCH.LEARNER.MOTIVATION_AFFECT` — support confidence, motivation and productive challenge.
- `TCH.LEARNER.DEVELOPMENTAL_ERROR` — distinguish developmental patterns from high-priority intervention needs.
- `TCH.LEARNER.L1_TRANSFER` — use linguistic-background knowledge carefully and diagnostically.
- `TCH.LEARNER.DIFFERENTIATION` — adjust support, route, task or pacing without lowering intended standards silently.
- `TCH.LEARNER.AUTONOMY` — develop learner planning, monitoring, strategy use and independence.
- `TCH.LEARNER.RETRIEVAL_RETENTION` — design opportunities for retrieval, spacing and retention.
- `TCH.LEARNER.INTERPRET_NEEDS` — interpret multiple forms of evidence to identify learner priorities.

# Stage performance progression

The same competency can deepen across stages.

## T1 — Emerging

Performance is reliable mainly in familiar, planned situations with guidance. Teacher can explain basic rationale after prompting.

## T2 — Developing

Performance becomes more consistent. Teacher adapts routine instruction based on visible learner needs and formative evidence.

## T3 — Proficient

Performance is autonomous across common contexts. Teacher diagnoses, justifies choices, designs units and transfers knowledge to new situations.

## T4 — Advanced

Teacher handles complex contexts, coaches others, designs systems, calibrates assessment and leads evidence-based improvement.

## T5 — Teacher Leader / Educator

Teacher develops other professionals, leads quality systems, designs professional learning and contributes validated knowledge/practice.

# Mastery rule

Professional mastery requires evidence at the correct performance level. For example:

- knowing that retrieval practice is valuable is not the same as designing it well;
- writing a lesson plan is not the same as implementing it responsively;
- identifying a pronunciation feature is not the same as teaching it effectively;
- recognizing a weak assessment item is not the same as designing and calibrating a valid performance assessment;
- using an AI tool is not the same as exercising responsible AI-supported professional judgment.

# Cross-product principle

Where authorized, Lurexa Teach may use evidence from Lurexa Learn and Lurexa Coach to support a teacher's own English development. Teacher professional competency IDs remain distinct from student English competency IDs.
