# Lurexa Teach T1 Production Learning Blueprints — Emerging Educator

Status: Implementation-ready professional-learning architecture  
Depends on: `00-LUREXA-TEACH-PROFESSIONAL-DEVELOPMENT-PROGRAM.md`, `01-TEACHER-COMPETENCY-FRAMEWORK.md`, `02-TEACHER-ASSESSMENT-PLACEMENT-AND-ADVANCEMENT.md`, `03-ASYNCHRONOUS-AI-ASSISTED-PROGRAM-DELIVERY.md`

## 1. Purpose

T1 must model the same Lurexa philosophy teachers are expected to use: asynchronous learning first, AI-assisted practice and rehearsal, authentic evidence, optional mentor/expert support, and advancement based on demonstrated capability rather than module completion.

## 2. T1 program outcome

By the end of T1, an emerging educator should be able to design, teach, assess and reflect on a coherent short learner-centered lesson with appropriate support.

## 3. Standard T1 learning cycle

Each module should normally use:

**Case/Encounter → Explain/Notice → Analyze → Practice Decision → Design → Rehearse With AI → Produce Artifact/Performance → Feedback → Revise → Reflect → Transfer**

AI assists but does not create the teacher's final evidence artifact.

# Module T1.1 — How Learning Happens

Performance outcome: analyze a learner case and choose support based on prior knowledge, attention, retrieval, motivation, cognitive load and developmental error.

### Learning experiences

- short learner-case stories;
- identify what learner already knows;
- distinguish practice from retrieval;
- compare overloaded vs scaffolded activities;
- diagnose confidence/motivation barriers without deficit framing;
- AI learner simulation showing different response patterns.

### AI role

Simulate learner responses and ask teacher to choose what to do next. Challenge simplistic explanations such as "the learner is lazy" when evidence supports more plausible instructional causes.

### Evidence

- case analysis;
- selected intervention + rationale;
- revised support plan after simulation;
- reflection identifying evidence still missing.

### Mentor/expert extension

Discuss ambiguous learner case; expert educator models how to separate observation, inference and intervention.

# Module T1.2 — Planning Lessons With a Purpose

Performance outcome: align learner outcome, activity sequence and evidence.

### Core competencies

- `TCH.DESIGN.WRITE_PERFORMANCE_OBJECTIVE`
- `TCH.DESIGN.ALIGN_OBJECTIVE_TASK_ASSESSMENT`
- `TCH.DESIGN.SEQUENCE_LEARNING`
- `TCH.DESIGN.BUILD_SCAFFOLDING`

### Async sequence

compare weak/strong objectives → diagnose misalignment → reorder lesson → write objective → build sequence → AI critique → revise → micro-plan.

### AI role

Ask alignment questions and flag mismatches; do not write final lesson plan automatically.

### Evidence

- original objective;
- activity/evidence map;
- revised aligned plan;
- rationale.

# Module T1.3 — Teaching Vocabulary and Grammar for Use

Performance outcome: transform passive explanation/worksheet work into meaningful language learning.

### Core

Vocabulary: See → Hear → Recognize → Pronounce → Retrieve → Use → Recall Later.

Grammar: Context → Notice → Meaning → Form → Controlled Practice → Guided Communication → Free Communication → Retrieval.

### AI simulation

Teacher explains a simple language target to an AI learner. The learner may misunderstand, answer incorrectly or ask a predictable question.

### Evidence

- redesigned worksheet sequence;
- brief explanation;
- practice task;
- communicative transfer task;
- feedback decision.

# Module T1.4 — Teaching Listening and Reading

Performance outcome: design a receptive-skills lesson that teaches processing rather than only checking answers.

### Async sequence

analyze weak comprehension lesson → predict/pre-task → global processing → detail → strategy/micro-focus → response/transfer.

### AI role

Act as a teacher-design reviewer and simulated learner; show where instructions or text difficulty create unnecessary barriers.

### Evidence

- staged receptive lesson;
- rationale for each stage;
- comprehension item audit;
- transfer task.

# Module T1.5 — Teaching Speaking and Writing

Performance outcome: move learners from controlled support toward independent production and provide useful feedback.

### Core

Speaking: Controlled → Guided → Interactive → Independent.

Writing: Analyze → Plan → Draft → Feedback → Revise → Submit → Reflect.

### AI rehearsal

Teacher conducts a short speaking task with simulated learner; chooses when to correct, prompt or wait.

### Evidence

- speaking/writing task design;
- scaffold plan;
- feedback sample;
- revision/second attempt analysis.

# Module T1.6 — Classroom Interaction and Feedback

Performance outcome: set up tasks clearly, ask productive questions, check understanding, create learner talk opportunities and give prioritized feedback.

### AI simulations

- learner says "I don't understand";
- learner gives one-word answer;
- learner makes communication-critical error;
- learner makes minor non-target error;
- group remains quiet;
- instructions are misunderstood.

Teacher chooses action and explains why.

### Evidence

- interaction decisions;
- task instructions;
- correction prioritization;
- 5–10 minute microteaching or simulation;
- self-reflection.

# T1 Capstone — The First Coherent Lesson

Teacher must:

1. identify learners/context;
2. write performance objective;
3. identify prior knowledge;
4. design coherent sequence;
5. include active learner production;
6. define evidence;
7. teach or simulate a meaningful segment;
8. give feedback;
9. analyze learner response/evidence;
10. revise the plan;
11. reflect on next professional target.

## AI role in capstone

AI may:

- ask planning questions;
- simulate learner behavior;
- flag alignment risks;
- help teacher rehearse language;
- critique rubric/evidence design.

AI must not:

- author the final lesson plan as teacher evidence;
- fabricate classroom evidence;
- declare T1 mastery independently;
- replace human/mentor review where authentic performance confidence is required.

## Mentor/expert educator role

Mentor or expert educator may:

- review difficult capstones;
- calibrate evaluation;
- coach instructional reasoning;
- model alternatives;
- help teacher identify one high-value next development goal.

Expert support should become reusable Teach case material when patterns recur.

# T1 advancement evidence bundle

Recommended minimum:

1. learner-case analysis;
2. aligned lesson objective/sequence;
3. vocabulary/grammar redesign artifact;
4. receptive-skills lesson artifact;
5. productive-skills task;
6. feedback/correction decision evidence;
7. microteaching/simulation;
8. capstone lesson;
9. reflection and revision.

Completion of six modules without these performance artifacts is not T1 mastery.

# Production acceptance criteria

T1 is production-ready when:

- every module works asynchronously;
- AI simulations require professional judgment rather than answer matching only;
- authentic/design evidence is preserved;
- teachers can challenge material they already demonstrate;
- mentor/expert support is available for ambiguity and calibration;
- final T1 decision uses a body of evidence rather than course completion.
