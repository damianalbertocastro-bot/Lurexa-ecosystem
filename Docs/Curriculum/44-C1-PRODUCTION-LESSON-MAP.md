# English C1 Production Lesson Map — Precision, Identity and Global Perspective

Status: Production lesson-authoring authority  
Depends on: `26-C1-COMPETENCY-MATRIX.md`, `35-C1-MODULE-AND-UNIT-BLUEPRINTS.md`

## 1. Production rule

C1 lessons should rely on demanding sources, nuanced stance, strategic register, facilitation, mediation, uncertainty and autonomous extended production. Scaffolds should mainly support strategy and review, not pre-compose language.
