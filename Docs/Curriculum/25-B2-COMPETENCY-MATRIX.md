# English B2 Competency Matrix — Flexible Communication

Status: Authoritative B2 curriculum-development matrix  
Framework: CEFR B2 with Companion Volume integration

## Level mission

B2 develops spontaneous, flexible communication across personal, academic, professional and public contexts. Learners should handle extended input, build supported arguments, adapt register, collaborate online, mediate complex-but-accessible information and communicate with reduced dependence on scaffolding.

## Evidence expectations

B2 mastery requires repeated evidence across independent production, interaction, synthesis, transfer and delayed retrieval. Recognition alone is insufficient.

## Exit evidence

B2 completion should include an extended spoken presentation, spontaneous interaction, structured argument in writing, multisource reading/listening synthesis, mediation task, professional/online interaction, pronunciation/discourse sample, Create & Apply artifact and delayed retrieval from earlier levels.

## Mastery rule

B2 means flexible independent performance across major communicative demands. It does not require native-like control and must not be inferred from isolated grammar accuracy.
