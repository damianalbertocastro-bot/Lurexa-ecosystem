# Curriculum Coverage and QA Gates

Status: Authoritative curriculum quality-control standard  
Applies to: Lurexa Learn and Lurexa Teach curriculum releases

## 1. Purpose

A level, module, unit, or professional-development stage is not complete because all planned files exist. It is complete only when coverage, evidence quality, async completeness, AI behavior, accessibility, and human-support design meet explicit release standards.

## 2. QA workflow

Every substantial curriculum object progresses through:

**Draft → Pedagogical Review → Linguistic/Content Review → Assessment Review → Async/AI Review → Accessibility/UX Review → Pilot → Evidence Review → Publish → Monitor**

A later stage may send work backward.

## 3. Required coverage dimensions

### Competency coverage

For each required competency record:

- where first encountered;
- where practiced;
- where independently demonstrated;
- where retrieved later;
- where transfer is expected;
- evidence types available;
- whether human validation is useful/required.

### Skill balance

English levels must audit:

- listening;
- speaking;
- reading;
- writing;
- vocabulary;
- grammar;
- phonetics;
- conversation;
- Create & Apply;
- mediation;
- online interaction;
- plurilingual/pluricultural competence.

Balance does not mean equal minutes. It means each required capability receives enough valid opportunities for its role at that CEFR level.

### Evidence quality

Audit whether evidence includes appropriate mixtures of:

- recognition;
- retrieval;
- guided production;
- independent production;
- interaction;
- transfer;
- delayed retrieval;
- human observation where useful.

No productive competency can rely exclusively on selected-response evidence.

### Async completeness

Check that:

- required learning can proceed without waiting for a live teacher;
- instructions are sufficient;
- help is available inside the learning experience;
- activities can resume after interruption;
- teacher support extends rather than repairs an incomplete digital curriculum.

### AI quality

Check:

- task/level constraints;
- evidence-aware scaffolding;
- productive struggle;
- no premature answer reveal;
- selective correction;
- learner agency;
- safe/appropriate escalation;
- uncertainty/provenance;
- no fabricated standards.

### Teacher support quality

Check:

- teacher brief exists where useful;
- suggested live work is evidence-driven;
- teacher can override recommendations;
- teacher observations return to learner/professional path;
- routine administration is minimized.

### Expert educator/mentor quality

Check:

- escalation criteria are clear;
- expert support is reserved for higher-value teacher/curriculum cases;
- recurring resolutions become reusable institutional knowledge;
- expert support increases independence rather than dependency.

### Retrieval and retention

Every major competency must have planned reappearance after initial instruction when retention matters.

### Cultural quality

Audit:

- local relevance;
- Dominican/Spanish-speaker specialization where useful;
- progression toward broader international/global contexts;
- avoidance of stereotypes;
- exposure to variation;
- learner-specific evidence overriding assumptions.

### Accessibility/UX

Audit:

- alternative modalities where required;
- captions/transcripts rules;
- keyboard interaction;
- readable instruction load;
- no pedagogically unnecessary time pressure;
- safe resume state;
- accessibility adaptation without silently lowering learning target.

## 4. Module release gate

A Learn module can move from pilot to publish when:

1. every unit has a performance goal;
2. required competencies have mapped evidence opportunities;
3. major productive targets include productive evidence;
4. async path is complete;
5. AI behavior is specified;
6. feedback/retry policy is specified;
7. at least one retrieval mechanism exists;
8. Create & Apply/transfer is present;
9. teacher extension is defined where useful;
10. accessibility/resume requirements are met;
11. pilot results reveal no unresolved critical defect.

## 5. Level release gate

A CEFR level can be represented as curriculum-complete when:

- all modules pass module gate;
- level competency matrix is complete;
- exit evidence portfolio is defined;
- coverage matrix contains no major unexplained gaps;
- phonetics progression is coherent;
- conversation progression is coherent;
- mediation/online/pluricultural integration is present;
- delayed retrieval exists across modules;
- level-exit tasks require integrated performance;
- teacher-supported and Flex routes preserve the same standards;
- pilot/calibration evidence exists for representative learning patterns.

## 6. Lurexa Teach release gate

A teacher-development module can publish when:

- target `TCH.*` competencies are explicit;
- knowledge and performance evidence are distinguished;
- async path can stand alone;
- AI simulation/rehearsal has bounded behavior;
- authentic/simulated professional performance is required where competency demands it;
- mentor/expert escalation is defined where appropriate;
- advancement is not awarded from completion alone.

## 7. Severity model

### Critical

Invalidates release:

- false mastery inference;
- learner can bypass required productive performance;
- AI routinely performs learner task;
- required async path depends on hidden teacher instruction;
- evidence/provenance cannot be trusted;
- serious accessibility blocker.

### Major

Release should normally wait:

- competency coverage gap;
- poor retrieval architecture;
- repeated AI level-control problem;
- teacher support duplicates async work;
- assessment underrepresents target performance.

### Minor

Can publish with tracked follow-up if risk is limited:

- wording inconsistency;
- noncritical example imbalance;
- small UX friction;
- optional enrichment gap.

## 8. Monitoring after publication

Monitor:

- first-attempt vs scaffolded success;
- dropout/failure hotspots;
- AI hint and reveal rates;
- competency evidence gaps;
- retrieval decay;
- teacher override patterns;
- expert-escalation recurrence;
- accessibility feedback;
- recurring learner misconceptions;
- recurring teacher confusion.

Repeated patterns should trigger curriculum review rather than endless learner-level remediation.

## 9. Definition of quality

High-quality Lurexa curriculum produces valid, traceable evidence of improved independent performance while allowing learners to progress asynchronously, benefit from AI, receive meaningful teacher support when available, and benefit from expert educator knowledge without making expert availability a bottleneck.
