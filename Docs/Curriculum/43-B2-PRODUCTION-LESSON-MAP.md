# English B2 Production Lesson Map — Flexible Communication

Status: Production lesson-authoring authority
Depends on: `25-B2-COMPETENCY-MATRIX.md`, `34-B2-MODULE-AND-UNIT-BLUEPRINTS.md`

## 1. Production rule

B2 lessons should require sustained turns, spontaneous response, audience/register choices, source use, synthesis, negotiation and mediation with substantially reduced scaffolding.

Each unit below contains two production lessons. Authors may split a lesson when necessary, but should preserve the performance/evidence sequence.

## B2 retrieval design

B2 retrieval should repeatedly require:

- B1 narrative/opinion/problem-solving under greater complexity;
- previous B2 source/stance language in new topics;
- professional negotiation after delay;
- synthesis with different sources;
- register and audience shifts;
- spontaneous pronunciation/discourse control under real communicative load.

## B2 production release rule

Blueprint completion does **not** mean B2 curriculum completion. B2 remains incomplete until representative lessons are authored into the runtime, productive/interactive evidence works as designed, delayed retrieval is exercised, and capstone performance is calibrated.
