# Teacher Proficiency and Development

Status: Future Lurexa Teach specification with MVP-compatible data assumptions

## Principle
Teacher language proficiency and teaching competence are related but distinct. Lurexa must never infer professional quality from CEFR level alone.

## Teacher profile dimensions
### Language proficiency
- listening
- speaking
- reading
- writing
- vocabulary
- grammar
- phonetics
- conversation/pragmatics

### Teaching competence
- lesson delivery
- communicative teaching
- feedback/correction
- CEFR literacy
- assessment literacy
- pronunciation teaching
- classroom interaction
- digital/AI teaching
- inclusive/culturally responsive practice

## Teacher placement
Teachers may take an adapted English diagnostic using the same evidence architecture as learners, with educator-relevant prompts and performance tasks.

Example output:
- overall English estimate: B2
- speaking: B2
- listening: C1-
- writing: B1+
- phonetics: B2-
- suggested growth targets: academic discussion, connected speech awareness, advanced writing feedback

## Suggested teaching bands
These are provisional product recommendations, not universal accreditation rules:
- B1+ language proficiency: primarily A1 with validated teaching competence
- B2: A1-A2
- B2+/C1: A1-B1
- C1: A1-B2
- C1+/C2: A1-C1
- C2 + validated advanced teaching competence: A1-C2

Do not hard-lock solely from one automated test. Institutions/admins may validate broader teaching range using observed teaching, credentials, sample lessons or review.

## Teacher growth path
Teachers should learn through the same core Lurexa cycle:
Encounter -> Understand -> Practice -> Retrieve -> Apply -> Create -> Feedback -> Improve -> Transfer -> Retain

Content must be professionally adapted. Examples:
- explain an error without overexplaining;
- model a phoneme for a Spanish-speaking learner;
- give corrective feedback after a presentation;
- assess a B1 speaking sample;
- facilitate disagreement;
- create a CEFR-aligned speaking task.

## Teacher Development Model
Keep teacher-development evidence conceptually separate from student-learning evidence even when the same identity owns both roles.

The model may include:
- teacher language profile;
- professional competency states;
- training completed;
- observed teaching evidence;
- development goals;
- suggested teaching range.

## AI recommendations
AI may recommend professional-development modules based on authorized evidence, but should explain the learning rationale and never present an automated proficiency result as professional certification.

## Future credentials
Certificates/badges may later represent:
- Lurexa English proficiency validation;
- CEFR assessment literacy;
- pronunciation teaching;
- AI-assisted teaching;
- Lurexa methodology certification.
Credential governance is a separate future policy.
