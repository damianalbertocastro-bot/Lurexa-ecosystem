# Interactive Activity Library

Status: MVP UX/pedagogy activity standard

## 1. Purpose

This document defines reusable activity families for Lurexa Learn. Activities must feel interactive, purposeful and level-appropriate. The UX should make learners do something meaningful rather than scroll through static lesson pages.

## 2. Core interaction rhythm

Prefer short cycles:

**Input → Interaction → Feedback → Production**

Avoid long passive blocks. Passive material should normally be followed quickly by a meaningful learner action.

## 3. Interactive Vocabulary Cards

Static flashcards are not the default.

A vocabulary item should be able to move through:

**See → Hear → Recognize → Pronounce → Retrieve → Use → Recall Later**

Possible modes:

- image → word;
- word → image;
- audio → select meaning;
- audio → type/rebuild;
- pronunciation recording;
- stress marking;
- collocation builder;
- sentence completion;
- context choice;
- image-only recall;
- definition-only recall;
- spoken retrieval;
- conversation reuse;
- later spaced recall.

Card behavior should adapt. If recognition is strong but production is weak, stop overusing recognition and require retrieval/use.

## 4. Vocabulary activity families

### Quick Reveal
Short exposure with audio, image/context and example.

### Listen & Select
Hear a word/phrase and choose the correct image, meaning or context.

### Build the Chunk
Construct common chunks/collocations.

### Retrieval Challenge
Prompt meaning/image/context without displaying the target English.

### Personal Connection
Use the item in a personally relevant choice or response.

### Say It
Record target word/phrase, receive focused phonetic feedback and retry.

## 5. Listening activity families

### Predict the Situation
Use image/title/context before audio.

### Global Listen
Identify speaker, purpose, situation or main idea.

### Detail Hunt
Identify names, times, prices, reasons, events or other target details.

### Micro-Listening
Replay a short difficult segment and focus on linking, reduction, sounds or boundaries.

### Interactive Transcript
Reveal/highlight selected language after initial listening, not as a substitute for listening.

### Listen and Respond
Learner answers orally or continues the dialogue.

## 6. Speaking activity families

### Repeat With Purpose
Brief controlled production tied to meaning.

### Guided Response
Sentence frames, prompts or cue cards.

### Picture/Scenario Talk
Describe or respond to a visual situation.

### Voice Note
Record short functional language.

### Timed Fluency
Higher levels speak for increasing periods with limited preparation.

### Presentation
Structured independent production.

## 7. Phonetics activity families

### Sound Discrimination
Choose what was heard.

### Contrast Practice
Use high-value contrasts only where relevant.

### Stress Tap
Mark/tap stressed syllable or word.

### Final Sound Check
Focus on communicatively important word endings.

### Shadowing
Imitate short natural chunks.

### Chunk and Breathe
Practice discourse chunking and pacing.

### Intonation Match
Imitate question, stance, politeness or rhetorical contour.

### Record → Feedback → Retry
Core Coach-compatible loop.

## 8. Grammar activity families

### Notice the Pattern
Highlight form in meaningful input.

### Meaning Choice
Choose what a structure communicates.

### Build the Sentence
Reorder/construct language.

### Fix the Message
Correct a meaningful error.

### Choose for Context
Select form based on communicative situation.

### Use It
Produce oral/written output using the target.

## 9. Reading activity families

### Predict
Use heading/image/context.

### Skim
Find main idea quickly.

### Scan
Locate specific information.

### Evidence Highlight
Select text supporting an answer.

### Reorder
Sequence events/paragraphs/steps.

### Infer
Identify unstated meaning, attitude or reference.

### Compare Texts
B1+ where appropriate.

### Respond
Oral/written reaction transferring reading to production.

## 10. Writing activity families

### Micro-Write
One sentence or short functional response.

### Guided Paragraph
Frames/checklist with decreasing support.

### Message/Email Simulation
Functional communication.

### Draft and Revise
Plan → draft → feedback → revision.

### Transform
Rewrite for purpose/register/clarity at higher levels.

### Create Artifact
Report, proposal, commentary, reflection, script or project text.

## 11. Conversation activity families

### Guided Exchange
Highly scaffolded turns.

### Roleplay
Defined roles and goal.

### Information Gap
Each participant has different information.

### Problem Solving
Reach a decision or solution.

### Opinion Exchange
State and respond to viewpoints.

### Negotiation
B2+ where appropriate.

### Debate/Panel
B2-C2, increasingly independent and nuanced.

## 12. Create & Apply families

- personal profile;
- map/guide;
- itinerary;
- interview;
- podcast;
- roleplay performance;
- presentation;
- campaign;
- proposal;
- cultural commentary;
- research brief;
- panel/capstone.

Each must state purpose, audience, competencies and success criteria.

## 13. Quiz activity families

Use varied review types:

- multiple choice;
- image choice;
- audio choice;
- matching;
- sorting;
- sequencing;
- fill-in;
- error correction;
- short answer;
- oral response;
- brief writing.

Do not make every quiz a static set of text multiple-choice questions.

## 14. Visual/card UX rules

Cards, illustrations and images should invite interaction when pedagogically useful:

- tap hotspots;
- swipe to compare;
- progressive reveal;
- audio trigger;
- drag/order;
- image-based recall;
- visual scenario branching;
- flip only when flip adds learning value.

Avoid decorative imagery that increases cognitive load without supporting meaning, memory, culture or task context.

## 15. Feedback UX

Feedback should be immediate when useful, concise and actionable. Use success states that explain what worked, not only celebratory animation.

For errors, show the highest-value correction and allow a retry. Preserve first-attempt evidence.

## 16. Accessibility

Interactive design must preserve:

- keyboard accessibility where applicable;
- readable text contrast;
- captions/transcripts with pedagogically appropriate reveal timing;
- alternatives for audio-only or visual-only interactions where required;
- clear focus states;
- touch-friendly controls;
- no dependence on color alone for meaning.

## 17. Level adaptation

A1-A2: short tasks, visuals, strong scaffolds, high-frequency chunks, immediate interaction.  
B1-B2: longer input, less scaffolding, more open responses, authentic/semi-authentic contexts.  
C1-C2: synthesis, nuance, ambiguous/complex material, sophisticated creation and interaction.

## 18. MVP component priority

Prioritize reusable components that can prove the vertical slice:

1. Interactive Vocabulary Card
2. Audio Player + listening question
3. Voice Recorder / speaking response
4. Phonetics practice card
5. Sentence/phrase builder
6. AI Conversation panel
7. Reading interaction
8. Short writing response
9. Quiz/review component
10. Create & Apply assignment card

Components should consume structured lesson/activity data rather than hard-coded lesson-specific markup.
