# A1 Competency × Evidence × Retrieval Map

Status: Authoritative A1 coverage map
Level: English A1 — Foundations for Real Communication
Depends on: `02-ENGLISH-COMPETENCY-MODEL.md`, `20-A1-MODULE-1-PRODUCTION-BLUEPRINT.md`, `31-A1-MODULES-2-8-PRODUCTION-BLUEPRINTS.md`

## 1. Purpose

This map makes the A1 release gate explicit. Every required A1 competency must have:

- a first meaningful encounter;
- sufficient practice;
- an appropriate independent evidence opportunity;
- later retrieval/transfer;
- evidence strength that matches the competency.

Module references use `M1`–`M8`. `Exit` means the Module 8 A1 portfolio/capstone.

No row below is a mastery guarantee. It is the minimum curriculum coverage plan from which actual learner evidence can be interpreted.

## 17. A1 evidence-strength minimums

Before A1 can be represented as level-complete for a learner, the evidence portfolio should contain at least:

- multiple independent listening samples;
- multiple spoken-production samples;
- at least two genuine multi-turn interaction samples from different contexts;
- reading across messages, descriptions and functional information;
- writing across personal sentences, description/message/routine;
- at least one functional transaction;
- at least one directions/location task;
- multiple Create & Apply artifacts;
- delayed retrieval evidence;
- communication-repair evidence;
- intelligibility observations embedded in real speech;
- evidence from Module 8 integrated performance.

This is a portfolio rule, not a fixed count-based mastery algorithm.

## 18. Coverage gaps to watch during authoring

High-risk gaps are:

1. reading/writing becoming underrepresented because speaking/AI features are more visible;
2. phonetics being reduced to raw recording without interpretation;
3. mediation/online/pluricultural competencies appearing only in documentation;
4. M8 becoming a repeated quiz instead of integrated performance;
5. recognition items dominating evidence volume and distorting Mind confidence;
6. delayed retrieval existing technically but not being authored against specific targets.

## 19. A1 release decision

A1 curriculum can pass its level gate only when:

- every competency row above has an implemented encounter/practice/evidence/retrieval path or an explicit documented exception;
- productive competencies have productive evidence;
- conversation competencies have interaction evidence;
- phonetics evidence is interpreted responsibly;
- cross-module retrieval is active;
- Module 8 portfolio is calibrated;
- representative learners can complete the async path without hidden teacher instruction;
- teacher/Coach evidence strengthens the same competency graph rather than creating parallel scores.
