# A1 Module 1 — Assessment and Live Practice Plan

Status: Production specification

## Module
Hello, This Is Me

## Assessment purpose
Verify whether the learner can use Module 1 language to perform basic personal introductions and understand equivalent input. Assessment is evidence collection, not a single pass/fail declaration of permanent A1 mastery.

## Evidence bundle
### Listening
Two short first-meeting recordings.
Tasks:
- identify name;
- identify origin;
- identify work/study role;
- recognize one clarification move.

### Reading
Simple profile/chat introduction.
Tasks:
- extract key personal details;
- distinguish self vs other-person information.

### Writing
4-6 connected sentences introducing self or a fictional person.
Success focuses:
- task completion;
- basic be/possessive control;
- understandable organization.

### Speaking
60-90 second introduction with optional keyword support.
Required functions:
- greeting;
- name;
- origin;
- work/study role;
- one person description or extra personal detail;
- closing.

### Conversation
Approximately 2 minutes with AI, teacher or peer.
Target behaviors:
- answer basic questions;
- ask at least two questions;
- use one clarification/repair strategy when needed;
- close appropriately.

### Phonetics
Sample selected phrases for:
- /h/ where relevant;
- final consonant intelligibility;
- word stress;
- number/alphabet clarity;
- basic sentence stress.
Do not produce an accent score.

### Vocabulary/grammar retrieval
Short no-notes section covering high-frequency Module 1 language.

## A1 Module 1 speaking rubric
Score each dimension with descriptors rather than native-speaker comparison.

### Task achievement
3 — completes nearly all required functions independently
2 — completes most with some prompting
1 — completes limited functions with substantial prompting
0 — unable to communicate required information

### Comprehensibility
3 — generally easy to understand for target A1 content
2 — understandable with occasional effort/repetition
1 — frequent breakdowns
0 — message mostly unintelligible

### Interaction
3 — responds and asks basic questions; uses repair appropriately
2 — responds reliably; limited initiation
1 — mostly one-word/scripted response
0 — cannot sustain exchange

### Language control
3 — target structures usually support meaning
2 — errors present but meaning usually clear
1 — errors frequently disrupt intended message
0 — insufficient evidence

### Phonetic intelligibility
3 — target phrases generally intelligible
2 — some recurring issues but communication succeeds
1 — recurring sound/stress issues cause breakdown
0 — insufficient/inaudible evidence

## AI feedback output
Return:
- one communication success;
- one language target;
- one pronunciation/fluency target if relevant;
- recommendation: continue / continue-with-review / targeted-review.

Do not tell the learner `You mastered A1` from this module.

# Optional Human Live Practice

## Recommended 90-minute session after Unit 1 or end of Module 1
### 1. Retrieval warm-up — 10 min
Fast introductions around the room/pairs. No notes for first attempt.

### 2. Name and clarification carousel — 15 min
Students meet multiple partners, exchange names, deliberately include one unfamiliar name and use repair language.

### 3. Pronunciation coaching — 15 min
Teacher targets only the highest-impact group/individual patterns observed asynchronously.

### 4. Information-gap profiles — 20 min
Pairs hold incomplete profile cards and must ask questions to complete missing information.

### 5. Create & Apply performance — 20 min
Students introduce a partner or fictional person to the group.

### 6. Feedback and retry — 5 min
One strength + one priority correction, then repeat target phrase/mini-turn.

### 7. Reflection/next target — 5 min
Student identifies one communication behavior to practice next.

## Two-session option
### Session A — Language Coaching
- alphabet/numbers;
- be/questions;
- phonetics;
- controlled-to-guided speaking.

### Session B — Communication Lab
- meet-and-greet scenarios;
- information gaps;
- partner introductions;
- Module 1 performance.

## Teacher assignment suggestions
AI may suggest these based on evidence:
- `My 45-Second Introduction` recording;
- partner interview;
- family/important-person profile;
- clarification challenge;
- pronunciation micro-task.

Teacher can accept, modify, regenerate or replace.

## Teacher evidence capture
Useful observations:
- `asked two personal questions without prompt`;
- `used Can you repeat that? after breakdown`;
- `phone-number comprehension remains inconsistent`;
- `final /t/ in meet became intelligible after modeling`.

Avoid vague notes such as `needs more English`.

## Free-tier relationship
The module remains complete asynchronously. Human practice adds interaction and higher-quality observation but is not required for the included free content to be pedagogically valid.
