# A1 Modules 2–8 Production Blueprints

Status: Production authoring authority for A1 beyond Module 1  
Prerequisite: `20-A1-MODULE-1-PRODUCTION-BLUEPRINT.md` and validated canonical `LessonRuntime` pattern  
Level: English A1 — Foundations for Real Communication

## 1. Purpose

This document converts A1 Modules 2–8 from macro-program descriptions into production-authoring blueprints.

It deliberately defines learning structure, performance, evidence, retrieval and product integration before final lesson prose. Authors may localize examples and dialogue, but should preserve competency/evidence intent.

## 2. A1 production rules

Every module must:

- preserve A1 communication load;
- include real listening and speaking;
- include at least one interpersonal/AI-roleplay experience per unit where appropriate;
- include learner-created evidence;
- distinguish recognition from production;
- retrieve earlier A1 language;
- schedule delayed retrieval after meaningful completion;
- expose Coach-compatible speaking targets;
- define a teacher extension that adds interaction/judgment rather than repeats digital instruction;
- keep Dominican relevance available without making all content Dominican-only.

# Module 2 — My World in Numbers

## Module mission

Learner can exchange numbers, ages, dates, times, prices and simple schedule information accurately enough for everyday communication.

## Core competencies

- `EN.A1.LISTEN.KEY_DETAILS`
- `EN.A1.LISTEN.PERSONAL_INFORMATION`
- `EN.A1.SPEAK.ASK_PERSONAL_QUESTIONS`
- `EN.A1.CONV.ASK_ANSWER_BASIC_QUESTIONS`
- `EN.A1.VOCAB.NUMBERS_TIME_DATES`
- `EN.A1.GRAMMAR.BE_QUESTIONS`
- `EN.A1.GRAMMAR.PREPOSITIONS_BASIC`
- `EN.A1.PHON.HIGH_VALUE_CONTRASTS`
- `EN.A1.PHON.WORD_STRESS`
- `EN.A1.WRITE.BASIC_FORM`
- `EN.A1.ONLINE.SHARE_BASIC_INFORMATION`
- `EN.A1.MED.RELAY_PERSONAL_DETAIL`

## Unit 2.1 — Numbers That Matter

### Lesson 2.1.1 — Phone Numbers and Personal Details

Mission: understand and say phone numbers, ages and basic contact details.

Evidence:

- listening key-detail selection from real audio;
- spoken number production;
- basic form completion;
- short roleplay exchanging contact information.

Retrieves from Module 1:

- name;
- country/nationality;
- `be` questions;
- clarification phrases.

Phonetics focus:

- digit grouping;
- zero/oh awareness;
- stress for correction;
- intelligible number sequences.

Coach hook: rapid number/contact-information exchange with repair after intentional misunderstanding.

### Lesson 2.1.2 — Ages, Addresses and Identifiers

Mission: exchange age and simple identifying/location information without overloading address conventions.

Evidence:

- listen and identify age/address detail;
- spoken answer to personal questions;
- relay one detail to a third participant;
- short supported digital profile entry.

Teacher extension: information-gap pair task using different profile cards.

## Unit 2.2 — Dates and Calendars

### Lesson 2.2.1 — Days, Months and Dates

Mission: understand and communicate common dates.

Evidence:

- listening discrimination;
- calendar interpretation;
- spoken birthday/date production;
- short written date exchange.

Phonetics focus:

- ordinal clarity where needed;
- teen/ty contrasts when dates contain relevant numbers;
- chunking month + date.

### Lesson 2.2.2 — My Week

Mission: say when simple activities happen.

Language:

- days;
- basic time prepositions;
- simple schedule chunks.

Evidence:

- build a personal weekly schedule;
- answer when-questions;
- online message sharing one available time.

Retrieval: personal introduction + occupation/student identity from Module 1.

## Unit 2.3 — Time, Prices and Appointments

### Lesson 2.3.1 — What Time Is It?

Mission: understand and communicate basic clock time.

Evidence:

- audio → clock matching;
- spoken time retrieval;
- short schedule comprehension;
- clarification after deliberately unclear time.

### Lesson 2.3.2 — How Much? When?

Mission: combine price/time information in predictable transactions and arrangements.

Evidence:

- identify price/time from audio;
- basic transaction roleplay;
- relay an appointment time or price;
- Create & Apply: arrange one simple appointment/activity.

## Module 2 Create & Apply

**My Week and My Plans** — learner creates a simple personal schedule and completes a short interaction arranging a time.

## Module 2 delayed retrieval

Recheck after 2–7 days:

- one phone/date detail from audio;
- one spontaneous time question/answer;
- one Module 1 introduction element inside the exchange.

# Module 3 — The People Around Me

## Module mission

Learner can identify, describe and talk simply about family, friends and familiar people.

## Core competencies

- `EN.A1.LISTEN.PERSONAL_INFORMATION`
- `EN.A1.SPEAK.INTRODUCE_OTHER`
- `EN.A1.SPEAK.DESCRIBE_PERSON`
- `EN.A1.READ.SHORT_DESCRIPTIONS`
- `EN.A1.WRITE.SHORT_DESCRIPTION`
- `EN.A1.VOCAB.FAMILY_PEOPLE`
- `EN.A1.GRAMMAR.POSSESSIVE_ADJECTIVES`
- `EN.A1.PHON.FINAL_CONSONANTS`
- `EN.A1.PHON.BASIC_CLUSTERS`
- `EN.A1.CREATE.FAMILY_PRESENTATION`
- `EN.A1.PRAG.TURN_TAKING_BASIC`

## Unit 3.1 — Family and Relationships

### Lesson 3.1.1 — Who Is This?

Mission: identify familiar people and relationships.

Evidence:

- listen/read a simple family profile;
- match relationship information;
- say who a person is;
- ask/answer simple family questions.

### Lesson 3.1.2 — My Family, My People

Mission: introduce one or more familiar people.

Evidence:

- spoken introduction of another person;
- short written profile;
- interpersonal follow-up questions.

Transfer note: allow learner-defined family/important-person structures; do not assume one family model.

## Unit 3.2 — Describing People

### Lesson 3.2.1 — What Is He/She/They Like?

Mission: use basic descriptive language for familiar people.

Evidence:

- comprehend short descriptions;
- produce 2–4 connected A1 sentences;
- identify adjective placement patterns.

### Lesson 3.2.2 — Find the Person

Mission: use description to identify a person in an information-gap task.

Evidence:

- listening details;
- speaking description;
- clarification/repetition strategy;
- AI-roleplay or partner guessing exchange.

Phonetics: final consonants and plural endings where they affect intelligibility.

## Unit 3.3 — People in My Community

### Lesson 3.3.1 — People I Know

Mission: identify roles and simple relationships in school/work/community contexts.

Retrieval:

- occupations from Module 1;
- numbers/ages from Module 2.

### Lesson 3.3.2 — Introduce Someone

Mission: introduce a familiar person to someone else.

Evidence:

- presentational speaking;
- short digital message/profile;
- interpersonal follow-up.

## Module 3 Create & Apply

**Someone Important to Me** — short audio/video or live-supported presentation plus follow-up questions.

Teacher extension: learner-to-learner information gap with spontaneous follow-up questions.

Coach hook: describe someone while Coach asks one clarification or follow-up question per turn.

# Module 4 — My Everyday Life

## Module mission

Learner can describe a basic routine, ask about daily activities, understand simple schedules and compare familiar routines.

## Core competencies

- `EN.A1.LISTEN.PREDICTABLE_EXCHANGES`
- `EN.A1.SPEAK.DESCRIBE_ROUTINE`
- `EN.A1.READ.SHORT_DESCRIPTIONS`
- `EN.A1.WRITE.SIMPLE_ROUTINE`
- `EN.A1.VOCAB.DAILY_ACTIVITIES`
- `EN.A1.GRAMMAR.PRESENT_SIMPLE`
- `EN.A1.GRAMMAR.PRESENT_SIMPLE_QUESTIONS`
- `EN.A1.PHON.FINAL_CONSONANTS`
- `EN.A1.PHON.BASIC_SENTENCE_STRESS`
- `EN.A1.CREATE.DAILY_ROUTINE`
- `EN.A1.ONLINE.SHARE_BASIC_INFORMATION`

## Unit 4.1 — My Day

### Lesson 4.1.1 — Everyday Actions

Mission: understand and use core routine verbs/chunks.

Evidence:

- audio/picture matching;
- retrieval of routine chunks;
- short spoken sequence.

### Lesson 4.1.2 — From Morning to Night

Mission: produce a simple ordered routine.

Evidence:

- 4–6 sentence spoken/written routine;
- sequencing language;
- Create & Apply draft.

## Unit 4.2 — Asking About Routines

### Lesson 4.2.1 — What Do You Do Every Day?

Mission: ask and answer present-simple routine questions.

Evidence:

- question-building retrieval;
- AI or partner routine interview;
- first-attempt question formation preserved.

Transfer-sensitive focus: auxiliary `do/does` and Spanish-to-English question-formation differences.

### Lesson 4.2.2 — He/She Does…

Mission: report a familiar person's routine.

Focus:

- third-person `-s`;
- final consonant intelligibility;
- subject/verb contrast.

Evidence:

- listen for third-person forms;
- describe another person's routine;
- delayed production repair after feedback.

## Unit 4.3 — Routines Are Different

### Lesson 4.3.1 — My Routine and Your Routine

Mission: compare simple daily patterns without requiring complex comparative grammar.

Evidence:

- exchange routine information;
- identify same/different features;
- one short written comparison.

### Lesson 4.3.2 — A Day in My Life

Mission: integrate time + routines + basic personal information.

Retrieves Modules 1–3.

## Module 4 Create & Apply

**A Day in My Life** — spoken routine with time markers plus a short follow-up conversation.

Coach hook: spontaneous routine interview with targeted third-person or question-formation retrieval where learner evidence warrants it.

Teacher extension: rotating interviews; teacher monitors question formation and third-person endings rather than reteaching present simple.

# Module 5 — Food, Flavor and Everyday Choices

## Module mission

Learner can identify common food, express wants/preferences, order in predictable food-service situations and understand basic price/quantity information.

## Core competencies

- `EN.A1.LISTEN.PREDICTABLE_EXCHANGES`
- `EN.A1.LISTEN.KEY_DETAILS`
- `EN.A1.SPEAK.BASIC_TRANSACTION`
- `EN.A1.SPEAK.EXPRESS_BASIC_PREFERENCE`
- `EN.A1.READ.FUNCTIONAL_INFORMATION`
- `EN.A1.VOCAB.FOOD_SHOPPING`
- `EN.A1.GRAMMAR.ARTICLES_BASIC`
- `EN.A1.GRAMMAR.COUNTABILITY_FOUNDATIONS`
- `EN.A1.GRAMMAR.SOME_ANY_BASIC`
- `EN.A1.CONV.BASIC_TRANSACTION`
- `EN.A1.CREATE.RESTAURANT_ROLEPLAY`
- `EN.A1.PRAG.BASIC_POLITENESS`

## Unit 5.1 — Food I Know

### Lesson 5.1.1 — Food Around Me

Mission: identify common foods and meals in local/international contexts.

Cultural rule: include Dominican examples as one part of a broader food repertoire.

Evidence:

- picture/audio recognition;
- vocabulary retrieval;
- short preference statements.

### Lesson 5.1.2 — What Do You Like?

Mission: ask/answer basic food preferences.

Evidence:

- interpersonal preference exchange;
- listen for preference details;
- short written recommendation.

## Unit 5.2 — Quantities and Choices

### Lesson 5.2.1 — A, Some, Any

Mission: understand/use high-frequency quantity patterns in context.

Evidence:

- controlled meaning-form practice;
- shopping-list creation;
- spoken request.

### Lesson 5.2.2 — What Do We Need?

Mission: plan a simple meal/list using quantity language.

Mediation: relay one needed item/quantity to another participant.

## Unit 5.3 — At a Café or Restaurant

### Lesson 5.3.1 — Reading a Menu

Mission: locate simple menu information and prices.

Evidence:

- functional reading;
- listening price/item match;
- selection with reason/preference.

### Lesson 5.3.2 — I'd Like…

Mission: complete a short polite ordering exchange.

Evidence:

- real model listening;
- recorded speaking;
- AI roleplay;
- communication repair if item/price is misunderstood.

## Module 5 Create & Apply

**Order for Real** — restaurant/café roleplay requiring greeting, request, clarification, price/quantity detail and closing politeness.

Coach hook: variable menu/availability scenario so learner cannot memorize one script.

Teacher extension: rotating server/customer roles with unexpected but A1-manageable changes.

# Module 8 — Life in Action

## Module mission

Integrate A1 competencies across practical situations with decreasing support and generate the strongest A1 exit evidence available in the program.

## Design principle

Module 8 introduces little new grammar. It increases integration, unpredictability, retrieval distance and independence.

## Unit 8.1 — Meet and Connect

### Lesson 8.1.1 — Meet Someone New

Integrates:

- greetings;
- name;
- origin;
- occupation/status;
- age/contact detail where appropriate;
- clarification;
- turn taking.

Evidence: AI/partner interpersonal conversation with reduced prompts.

### Lesson 8.1.2 — Introduce Someone Else

Integrates Modules 1 and 3.

Evidence: spoken introduction + follow-up questions.

## Unit 8.2 — Everyday Tasks

### Lesson 8.2.1 — Arrange a Time

Integrates Module 2 + Module 7.

Evidence: schedule interpretation + invitation/appointment conversation.

### Lesson 8.2.2 — Order and Solve a Small Problem

Integrates Module 5 plus clarification strategies.

Scenario variation:

- item unavailable;
- price misunderstood;
- simple substitution needed.

### Lesson 8.2.3 — Find a Place

Integrates Module 6.

Evidence: directions + route comprehension + repair.

## Unit 8.3 — My A1 Portfolio

### Lesson 8.3.1 — My Life in English

Learner assembles/revises:

- personal introduction;
- person/family description;
- daily routine;
- preference/social plan;
- practical location/food task evidence.

Reflection focuses on demonstrated capabilities, not completion counts.

### Lesson 8.3.2 — A1 Conversation Challenge

Multi-scenario interaction with bounded variability.

Requirements:

- answer and ask questions;
- initiate at least one turn;
- request clarification if needed;
- retrieve language from several modules;
- complete communicative purpose.

### Lesson 8.3.3 — Capstone: My Life, My English

Evidence portfolio:

1. presentational speaking;
2. interpersonal conversation;
3. listening detail task;
4. functional reading;
5. short writing;
6. practical mediation/relay task;
7. phonetic/intelligibility observations embedded in speech;
8. reflection and goal setting.

No single artifact establishes the whole A1 level.

## A1 exit interpretation

A1 completion should produce a competency/evidence profile rather than only pass/fail.

Possible outcome categories:

- ready for normal A2 progression;
- A2 progression + targeted A1 retrieval;
- targeted A1 consolidation before A2;
- insufficient evidence in one or more major productive/interactive domains.

The learner may progress while retaining targeted retrieval; progression and mastery need not be identical.

## A1 Coach integration map

Coach should recycle:

- M1 identity/introduction;
- M2 numbers/time/details;
- M3 people descriptions;
- M4 routines/questions;
- M5 transactions/preferences;
- M6 directions/clarification;
- M7 invitations/social planning;
- M8 integrated unpredictable scenarios.

Coach should prefer spontaneous variation over repeating Learn scripts verbatim.

## A1 teacher integration map

Teacher-supported sessions should prioritize:

- interpersonal interaction;
- production gaps hidden by recognition success;
- intelligibility problems with communicative impact;
- question formation;
- third-person/final-ending evidence where persistent;
- communication repair;
- capstone observation/calibration.

Teacher sessions should not become module lectures.

## A1 retrieval architecture

Each module should schedule at least:

- near retrieval within the same module;
- delayed retrieval 2–7 days later;
- cross-module retrieval in at least one later module;
- Module 8 integration.

Suggested recurrence:

| Earlier module | First required cross-module retrieval |
|---|---|
| M1 Introduction | M2 personal details; M3 introducing people |
| M2 Numbers/time | M4 routine times; M5 prices; M7 plans |
| M3 People | M4 describing another routine; M8 introduction |
| M4 Routines | M7 availability; M8 portfolio |
| M5 Transactions | M8 everyday task |
| M6 Directions | M8 everyday task |
| M7 Social plans | M8 arrange-a-time task |

## A1 publish gate

A1 should not be represented as curriculum-complete until:

1. Modules 1–8 pass the module QA gate;
2. competency × evidence coverage has no unexplained productive gaps;
3. each major speaking/conversation competency has real interaction/production evidence;
4. delayed retrieval has been exercised across module boundaries;
5. A1 exit portfolio has been piloted;
6. Coach practice does not contradict Learn competency state;
7. teacher observations return to learner recommendations;
8. accessibility/resume works across representative activity families.
