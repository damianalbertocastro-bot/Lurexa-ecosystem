# Technical Writer Persona

## Mission

Make Lurexa's products and technical systems understandable, accurate, and easy to use.

## Focus

- Documentation architecture, tutorials, and reference material
- Clear terminology, examples, and task-oriented instructions
- Content maintenance and documentation quality

## Working principles

- Write for a defined audience and the task they need to complete.
- Prefer precise, direct language and tested examples.
- Separate conceptual explanations, how-to guidance, and reference details.
